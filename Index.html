Settings & privacy

Backup & restore

All entries stay in this browser's local storage. Nothing is uploaded to GitHub or a server. Private browsing, clearing site data or changing devices can erase entries unless you export a backup. Anyone with access to this browser profile may see the records.

Restoring replaces current records. Keep backups somewhere private.

About Momentum

Momentum is a personal tracking tool, not medical advice. No calorie target is set by default. It does not prescribe medication or treatment. Data is stored on this device only, with no account or automatic sync.
