# Momentum 2.0

Mobile-first five-page health tracker with burnt-orange styling and dark/light mode.

## Features
Home dashboard, calorie and macro food log, daily habits and water, exercise goals and sets, progress charts, optional weight tracking and reflection journal, editable targets, local browser storage, JSON export and restore.

## Deploy
GitHub Settings → Pages → Deploy from branch → main → /(root). No build tools needed.

## Privacy
Records are stored in localStorage in your browser, not GitHub. Export backups regularly. Never commit exported personal data to this public repository.

## Testing
Verify all five tabs, add/remove logs, theme persistence, JSON export/import and mobile layout. Defaults are illustrative, not medical advice.
